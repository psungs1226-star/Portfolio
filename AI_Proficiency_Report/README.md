## AX 인재전쟁

선택한 기업·산업·고객의 공개적으로 검증 가능한 문제를 정의하고, 이를 해결하는 Codex 플러그인을 제작하는 대회입니다. 카카오페이증권·메디테라피·삼일PwC를 대상으로 각각 별도 문제와 플러그인을 제출했고 **예선 상위 10%**의 결과를 얻었습니다.

상세 문제 정의, 구현과 검증은 [AX 기업 문제 해결 3건](../Jocoding_AX_Output/)에서 확인할 수 있습니다.
