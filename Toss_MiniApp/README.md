## ⭐ Featured: 사주 다이어리

사주 다이어리는 단순 운세 콘텐츠나 기능 모음이 아닙니다. 운세를 보려면 운세 앱, 날씨는 날씨 앱, 할 일과 D-day는 일정 앱, 메모와 일기는 기록 앱을 각각 찾아 켜야 하는 불편을 **한 제품이 흡수하는 전략**에서 출발했습니다.

운세가 첫 방문을 만들고, 날씨·할 일이 하루 중 다시 쓸 이유를 늘리며, 메모·일기는 기록이 쌓일수록 다른 앱으로 이동하기 어렵게 만듭니다. 서로 다른 사용 목적을 연결해 **AU(활성 사용자)와 반복 방문을 확보할 수 있는 구조**로 설계했고, 실제 Apps in Toss 제품으로 출시해 이 가설을 검증할 기반을 만들었습니다.

- 같은 생년월일과 날짜에는 같은 결과가 나오는 결정론적 운세 엔진
- 민감정보를 서버에 저장하지 않는 로컬 우선 구조
- 서버가 필요한 푸시 알림은 제외하고, 일진 변화·기록·공유로 재방문 설계
- 사용자 피드백을 Phase 6~14 개선 사이클에 반영

상세한 제품 판단과 기술 구조는 [사주 다이어리 README](Saju_Diary/)에서 확인할 수 있습니다.
