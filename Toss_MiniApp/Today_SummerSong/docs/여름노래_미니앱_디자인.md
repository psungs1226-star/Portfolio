작성일: 2026년 7월 6일 · 실행계획서와 함께 보는 화면설계 문서

## 1. 디자인 방향

여름 감성을 담되, **강조색 하나만 쨍하게** 쓰고 나머지는 차분하게 가는 "액센트 원톤" 전략이다. 토스 심사가 절제된 톤·완성도를 선호하는 점과, 여름다운 생동감을 동시에 만족시키기 위한 균형점이다.

- **베이스**: 따뜻한 크림톤 배경(순백 대신)으로 여름의 온기를 은은하게 깔기
- **강조**: 노을빛 코랄을 "오늘의 여름노래" 히어로와 주요 CTA·활성 상태에만 집중
- **나머지**: 무드 타일·연도 칩·탭은 흰 카드 + 뮤트 톤으로 시선 분산 최소화
- **라이트 모드 전용** (토스 정책)

> 원칙: 화면에서 쨍한 색은 한 번에 한 곳(오늘의 곡)만. 사용자 시선이 "오늘 들을 곡 → 재생"으로 자연스럽게 흐르게 한다.

## 3. 카테고리 체계

무드가 겹치지 않도록 **분류 축을 둘로 분리**한다. 감정으로 찾는 사용자와 상황으로 찾는 사용자를 모두 커버한다.

**무드로 듣기 (감정 축)** — 상큼발랄 · 청량시원 · 설렘두근 · 센치감성
**순간으로 듣기 (상황 축)** — 바다 · 드라이브 · 밤바다 · 비 오는 날
**아티스트로 듣기 (그룹 축)** — 여자아이돌 · 남자아이돌

- 무드·순간 축은 **4개씩 2×2 그리드**, 아티스트 축은 **2개(1×2)**로 정렬
- 기존 "물놀이"는 **"바다"에 흡수**(해변+물놀이 포괄), "밤바다"는 낮 바다와 시간대·분위기가 달라 유지
- "비 오는 날"을 상황 축에 신규 추가, "상큼발랄"을 감정 축 대표 무드로 배치
- **아티스트 축(신규)**: 20~30대 여성 중심 타겟의 K-pop·플레이리스트 소비 습관을 반영. 큐레이션 톤은 **여자아이돌=상큼 계열, 남자아이돌=청량 계열**을 앞세우되, 곡별 무드는 실제 곡 기준으로 태깅

### 큐레이션 규칙 (겹침 방지)
- 곡마다 **무드는 딱 하나**(대표 감정)만 지정
- **순간은 여러 개** 지정 가능
- 예: "여름 안에서" → 무드=청량시원(1개), 순간=바다·드라이브(다중)
- 아이돌 곡은 **그룹 태그(여돌/남돌)**를 함께 부여(솔로·밴드·힙합은 미태그)
- 효과: 한 곡이 여러 상황에 노출돼도 감정 분류는 흐려지지 않음

## 4. 화면 설계

### 4-1. 홈
- 상단 내비게이션 바: 뒤로가기 · (해 아이콘)오늘의 여름노래 · 더보기(⋯) — 토스 비게임 내비게이션 규격
- **오늘의 여름노래 히어로**(코랄, 유일한 강조 영역): 라벨 + 곡명 + 아티스트·연도 + [유튜브]/[유튜브뮤직] 버튼, 우상단 해(썬) 포인트
- **오늘의 무드는?**: 무드/순간 카테고리 2×2 진입 타일(흰 카드 + 뮤트 아이콘)
- **그 해 여름**: 연도 칩(웜그레이 톤)
- 하단: 토스 스타일 플로팅 탭 — 홈(활성=코랄) · 무드 · 연도 · 찜

### 4-2. 무드 플레이리스트
- 내비게이션: 뒤로가기 · 카테고리명 · 더보기
- 헤더: 카테고리 태그 + 제목 + 부제("선선한 여름밤 감성 · 12곡")
- 곡 리스트(행): 썸네일 · 곡명/아티스트 · 유튜브 아이콘 · 찜(하트)
- 하단 플로팅 탭(무드 활성)

### 4-3. 곡 상세 (재생 연결)
- 대형 썸네일(공식 영상 썸네일) 중앙 배치
- 곡명 · 아티스트·연도·무드
- "어디에서 들을까요?" → **[유튜브에서 듣기]**(빨강 채움) / **[유튜브 뮤직에서 듣기]**(빨강 아웃라인)
- 보조: 찜하기 · 공유
- 안내 문구: "공식 영상으로 연결돼요 · 앱이 없으면 브라우저로 열려요"

## 5. 플랫폼 연동 & 썸네일 처리

### 5-1. 링크 (openURL)
곡마다 `videoId` 하나만 저장하고 나머지는 파생한다.
```
videoId: "abcd1234"
→ 썸네일:    https://img.youtube.com/vi/abcd1234/hqdefault.jpg
→ 유튜브:     https://youtu.be/abcd1234
→ 유튜브뮤직:  https://music.youtube.com/watch?v=abcd1234
```
재생은 `openURL(...)`(`@apps-in-toss/web-framework`)로 유튜브/유튜브뮤직 앱 또는 브라우저에 위임한다. `youtubemusic://` 같은 커스텀 스킴 대신 **https 유니버설 링크**를 써서 앱 미설치 시 웹으로 자연 폴백.

### 5-2. 썸네일 (번들에 이미지 0개)
- 이미지를 앱에 넣지 않고, `img.youtube.com/vi/<ID>/...`를 **런타임에 CDN에서 로드**
- 리스트 이미지는 `loading="lazy"`로 스크롤 시에만 로드 (성능·데이터 절약)
- 영상 삭제 등으로 404 시 **컬러 타일 + 음표 아이콘**으로 폴백(`onerror`)
- 크기는 `hqdefault`(약 10~20KB)면 충분

## 6. 컴포넌트 규격 요약

- 카드: 흰 배경, `0.5px solid #EFE8DD` 테두리, radius 12px, padding 10px
- 히어로: 코랄 배경, radius 18px, 우상단 해 원(circle) 포인트
- 버튼(주): 채움 CTA는 radius 8~12px, 아이콘+텍스트 중앙 정렬
- 칩/태그: radius 20px(pill)
- 폰트 굵기: 400(본문)·500(강조) 2단계만 사용
- 문구: 문장형(sentence case), 과한 유행어·비속어 금지 (토스 UX 라이팅 가이드)
