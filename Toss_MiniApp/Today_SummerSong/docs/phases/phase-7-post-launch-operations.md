# Phase 7. 출시 후 운영

## 목표

8/1~8/26 노출 기간 동안 앱 품질과 지표를 지속적으로 개선한다.

## 작업

1. 링크 모니터링을 한다.
   - 깨진 유튜브 링크 확인
   - 삭제/비공개 영상 교체
   - 썸네일 실패 확인
2. 큐레이션을 업데이트한다.
   - 반응 좋은 무드 강화
   - 부족한 연도 보완
   - 시즌감 높은 곡 추가
3. 공유 문구를 개선한다.
   - 클릭률 낮은 문구 교체
   - 곡 공유 문구와 플레이리스트 공유 문구 분리
4. 지표를 리뷰한다.
   - 방문
   - 재방문
   - 오늘의 곡 클릭
   - 유튜브 열기
   - 찜하기
   - 공유하기
5. 운영 업데이트를 배포한다.
   - 데이터 교체
   - 카피 수정
   - UI 마찰 제거

## 완료 조건

- 노출 기간 중 링크 오류에 대응함
- 지표 기반으로 큐레이션과 공유 문구를 개선함
- 앱 품질 저하 없이 업데이트를 유지함

## 산출물

- 운영 로그
- 링크 교체 내역
- 지표 리뷰 메모
- 업데이트 릴리즈 노트

## 리뷰 요청 기준

리뷰어는 다음을 확인한다.

- 운영 개선이 지표와 연결되어 있는가
- 링크 교체가 공식 링크 기준을 유지하는가
- 업데이트가 기존 기능을 깨뜨리지 않는가
- 8월 심사 기간 동안 집중해야 할 개선점이 명확한가
