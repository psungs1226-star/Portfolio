# Phase 0. 콘솔/브랜딩 준비

## 목표

앱인토스 콘솔 등록과 챌린지 제출에 필요한 기본 정보를 확정한다. 이 phase의 결과물은 개발 전에도 바로 콘솔에 입력할 수 있어야 한다.

## 입력 자료

- 앱 이름: `오늘의 여름노래`
- appName: `summer-song`
- 앱 가치: `매일 여름노래 추천`
- 상세설명: 실행계획 문서의 콘솔 등록 문구
- 로고: `assets/app-logo-600.png`
- 썸네일: `assets/app-thumbnail-1932x828.png`
- 검색 키워드 후보

## 작업

1. 앱 이름과 appName 확정값을 모든 문서에 동일하게 반영한다.
2. 콘솔 입력용 앱 가치 문구가 20자 이내인지 확인한다.
3. 상세설명이 다음 조건을 만족하는지 확인한다.
   - 여름 주제와 직접 연결됨
   - 음악 스트리밍 앱이 아니라 큐레이션/발견 앱으로 설명됨
   - 공식 유튜브/유튜브뮤직 연결 방식이 명확함
   - 과장된 기능 설명이나 리워드성 문구가 없음
4. 로고 파일이 600×600 PNG인지 확인한다.
5. 썸네일 파일이 1932×828 PNG인지 확인한다.
6. 검색 키워드는 10~15개로 정리하고 중복 의미의 키워드를 줄인다.
7. 콘솔 등록 완료 후 등록값을 실행계획 문서에 기록한다.
8. 콘솔에 업로드한 로고/아이콘 URL 또는 앱 설정에서 요구하는 이미지 URL을 확보한다.
   - Phase 2의 `granite.config.ts` `brand.icon` 입력값으로 전달
   - 아직 URL이 발급되지 않으면 Phase 6 업로드 전 확인 항목으로 남김

## 완료 조건

- 콘솔에 입력할 앱 이름, appName, 가치, 상세설명, 키워드가 확정됨
- 로고/썸네일 파일 크기가 요구사항과 일치함
- `granite.config.ts`에 반영할 아이콘 URL 확보 여부가 기록됨
- 실행계획 문서와 디자인 문서의 앱 이름이 모두 `오늘의 여름노래`로 통일됨

## 산출물

- 앱인토스 콘솔 등록 정보
- 아이콘/브랜드 이미지 URL 또는 미확보 사유
- `assets/app-logo-600.png`
- `assets/app-thumbnail-1932x828.png`
- 업데이트된 실행계획/디자인 문서

## 리뷰 요청 기준

리뷰어는 다음을 확인한다.

- 앱 이름과 appName이 혼용되지 않았는가
- 상세설명이 정책 리스크 없이 앱의 가치를 설명하는가
- 썸네일이 20~30대 여성 중심 타겟에 맞는가
- 제출 자산의 해상도와 파일 형식이 정확한가
