# Phase 3. MVP 품질 보강

## 목표

MVP가 단순 링크 목록으로 보이지 않도록 재방문, 저장, 오류 처리, 문구 완성도를 보강한다.

## 작업

1. 오늘의 곡 날짜 로직을 구현한다.
   - 서버 없이 날짜 기반 seed 사용
   - 같은 날짜에는 같은 곡 노출
   - 다음 날에는 다른 곡 노출
2. 찜하기 기능을 구현한다.
   - Storage에 곡 id 저장
   - 저장/해제 토글
   - 찜 목록 화면 표시
   - 앱 재접속 후에도 유지
3. 썸네일 폴백을 구현한다.
   - 유튜브 썸네일 로딩 실패 시 컬러 타일 표시
   - 폴백 타일에 곡명/음표 아이콘 표시
4. 빈 상태를 구현한다.
   - 찜한 곡 없음
   - 해당 연도 곡 없음
   - 해당 필터 결과 없음
5. UX 문구를 정리한다.
   - “공식 영상으로 연결돼요”
   - “앱이 없으면 브라우저로 열려요”
   - 음원 직접 재생처럼 오해되는 문구 제거
6. 20~30대 여성 중심 타겟 기준으로 UX/비주얼을 디벨롭한다.
   - 트렌디하지만 과하게 유치하지 않은 문구와 톤 유지
   - 홈 첫 화면에서 "오늘 들을 곡"이 가장 먼저 읽히는지 확인
   - 무드/순간/연도 진입점이 반복 사용하기 쉽게 보이는지 확인
   - 버튼, 카드, 하단 탭의 크기와 간격이 모바일 한 손 조작에 맞는지 확인
   - 코랄 액센트가 CTA와 활성 상태에만 집중되는지 확인
7. 필요한 이미지 자산을 판단하고 반영한다.
   - 곡 썸네일은 공식 YouTube 썸네일을 우선 사용
   - 저작권 있는 앨범아트/사진을 임의 번들링하지 않음
   - 썸네일 실패 폴백, 빈 상태, 콘솔용 보조 그래픽이 부족하면 생성 이미지 사용
   - 생성 이미지는 여름/K-pop/플레이리스트 감성은 살리되 특정 아티스트·앨범처럼 보이지 않게 제작
8. 인터랙션 품질을 확인한다.
   - 버튼 터치 영역
   - 스크롤 안정성
   - 리스트 이미지 lazy loading

## 완료 조건

- 오늘의 곡이 날짜에 따라 결정됨
- 찜하기가 저장/해제/재접속 유지까지 동작함
- 썸네일 실패와 빈 상태가 깨지지 않음
- 앱 문구가 정책 리스크 없이 명확함
- 20~30대 여성 중심 타겟 기준으로 첫 화면, 카테고리, 찜 화면의 UX/비주얼이 어색하지 않음
- 필요한 생성 이미지가 있으면 앱 또는 콘솔 자산으로 반영되고, 필요 없으면 사유가 리뷰 문서에 남음

## 산출물

- 날짜 기반 추천 로직
- Storage 기반 찜 기능
- 폴백/빈 상태 UI
- UX 문구 최종안
- UX/비주얼 점검 메모
- 이미지 자산 사용 여부와 근거

## 리뷰 요청 기준

리뷰어는 다음을 확인한다.

- 재방문 장치가 실제로 동작하는가
- Storage 사용이 안정적인가
- 저작권/스트리밍 오해를 만드는 문구가 없는가
- 오류 상태에서 사용자 경험이 깨지지 않는가
- 디자인이 20~30대 여성 중심 타겟에 맞고, 단순 링크 목록처럼 보이지 않는가
- 생성 이미지 또는 공식 썸네일 사용 기준이 정책 리스크 없이 적용되었는가
