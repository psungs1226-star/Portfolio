# Phase 4. 데이터 확장

## 목표

MVP 20곡을 출시 후보 데이터로 확장한다. 전체 300곡 중 우선순위가 높은 곡부터 검증해 실제 앱 데이터에 반영한다.

## 입력 자료

- `여름노래_큐레이션_마스터.xlsx`
- MVP `songs.json`
- 링크 검증 기준
- Phase 1 링크 검증 메모와 제외 사유

## 작업

1. 출시 후보 80~120곡을 우선 선정한다.
2. 선정 기준을 적용한다.
   - 20~30대 여성 중심 타겟 적합도 높음
   - 여름 계절감 명확
   - 무드/순간 카테고리 대표성 있음
   - 공식 영상 확보 가능
3. 각 곡의 공식 videoId를 검증한다.
   - YouTube oEmbed 또는 실제 페이지 접근으로 접근성 확인
   - 제목/채널명으로 공식 MV, 공식 채널, 소속사/레이블 채널, Topic 채널 여부 확인
   - `https://youtu.be/{videoId}`, `https://music.youtube.com/watch?v={videoId}`, `https://img.youtube.com/vi/{videoId}/hqdefault.jpg` 파생 가능 여부 확인
4. 부적합 곡을 제외하고 사유를 남긴다.
   - 공식 영상 없음
   - 계절감 약함
   - 저작권 리스크 있음
   - 링크가 불안정함
   - 404, 비공식 재업로드, 일반 가사 영상, 팬메이드 영상
5. JSON을 재생성한다.
   - Phase 1 `songs.json` 스키마 계약 유지
   - URL 전체가 아니라 `videoId`만 저장
6. 카테고리별 곡 수를 확인한다.
   - 무드별 최소 곡 수
   - 순간별 최소 곡 수
   - 연도별 빈 구간 여부
   - Phase 1에서 상대적으로 적었던 `비오는날`/`센치감성` 보강 여부
   - 2012~2024 구간이 20~30대 여성 중심 타겟의 추억/최신감 기준으로 충분한지 확인
   - MVP에서 연도별 곡 수가 적은 것은 허용하지만, 출시 후보 데이터에서는 연도별 리스트가 빈약하지 않게 보강

## 완료 조건

- 출시 후보 데이터가 최소 80곡 이상 확보됨
- 모든 앱 포함 곡에 공식 videoId가 있음
- 모든 앱 포함 곡이 Phase 1 `songs.json` 스키마 계약을 통과함
- 무드/순간/연도 화면이 빈약하지 않음
- 2012~2024 주요 연도에 20~30대 여성 중심 타겟이 기억하거나 발견할 만한 곡이 충분히 포함됨
- 비공식 링크가 포함되지 않음
- 제외 곡 목록에 제외 사유가 남아 있음

## 산출물

- 확장된 `songs.json`
- 제외 곡 목록과 사유
- 카테고리별 집계
- 링크 검증 로그 또는 메모

## 리뷰 요청 기준

리뷰어는 다음을 확인한다.

- 공식 링크 기준이 일관되게 적용되었는가
- 큐레이션이 20~30대 여성 중심 타겟에 맞는가
- 특정 무드나 연도에 과도하게 편중되지 않았는가
- 앱 데이터로 쓰기에 정책 리스크가 낮은가
