02 / 05 · ABOUT

새로운 문제를 학습해 실행 결과로 옮깁니다

지방자치단체 공무원으로 5년 6개월간 사업기획, 예산·계약, 채용·급여, 공사·용역 감독과 유관기관 협의를 담당했습니다. 복잡한 규정과 요구사항을 실행 가능한 업무로 구조화하고, 여러 이해관계자를 조율하며, 판단의 근거를 문서로 남기는 태도를 갖췄습니다.

2026년 4월 퇴직한 뒤 이 실무 역량에 AI 에이전트를 결합했습니다. 새로운 도메인의 자료를 빠르게 조사하고, 문제와 판단 기준을 정리해 제품·분석도구·자동화 시스템으로 구현하는 방식이 제 강점과 맞다는 것을 확인했습니다.

출발점보다 중요한 것은 얼마나 빠르게 배우고, 실제 문제에 적용하고, 검증 가능한 결과로 전환하는가입니다. 도메인이 달라져도 조사, 구조화, 구현, 검증의 흐름은 반복할 수 있다고 생각합니다.

01사내 데이터 챗봇 선행 검증

인사ON → PDF-to-Bot MCP

사내 규정 챗봇은 실제 데이터의 기밀성 때문에 검증이 어렵습니다. 공개된 공무원 인사 법령을 대체 corpus로 사용해 검색·근거·안전 구조를 먼저 검증하고, 검증한 계층을 임의의 PDF에 적용 가능한 MCP로 확장했습니다.

공개 재현용 corpus에서 휴직기간·복직일·지급 반기를 함께 판단해 근거 조문과 함께 답변하는 실제 실행 화면

"2025년 5월 말부터 육아휴직을 사용하고 2026년 4월 1일 복직했습니다. 2026년 상반기 정근수당은 100% 지급되나요, 50% 지급되나요?" 답변 : 100%, 실제 근무 6개월. 제6조·제14조 근거 반환
구현
조건추출 → temporal filter → hybrid retrieval → reranker → citation validation
검증
636 tests, B0→H3 ablation, distractor corpus, 합성 회귀셋 70건
핵심 판단
조건이 부족하면 재질문하고, 근거가 부족하면 답변을 중단
다음 확장
PDF 추출·청킹·검색·출처 반환 계층을 범용화한 PDF-to-Bot MCP, Claude Code 연동 및 MCP Inspector 검증 완료
한계 공개 : 법률 정답성 및 실사용자 효과는 미측정 상태이며, 로컬 추론 p50 62.9초입니다.
