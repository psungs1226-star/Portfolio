| 구분 | 조건 | 결과물 |
|---|---|---|
| A | 스킬 미사용 | [`A-no-skill/index.html`](A-no-skill/index.html) |

- 이 실험은 단일 사례의 정성 비교이며 통계적 우위를 의미하지 않습니다.
