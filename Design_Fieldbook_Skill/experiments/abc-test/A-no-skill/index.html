About

01

인사ON → PDF-to-Bot MCP

사내 규정 챗봇은 기밀성 때문에 실데이터 검증이 어렵습니다. 그래서 공개된 공무원 인사 법령을 사내 규정의 대체 corpus로 사용해, 개정 이력·조건 분기·예외가 많은 난점을 먼저 재현하고 검증했습니다.

“2025년 5월 말 육아휴직 사용, 2026년 4월 1일 복직 시 상반기 정근수당은?” — 휴직기간·복직일·지급 반기를 함께 판단해 근거 조문과 함께 “100%·실제 근무 6개월”을 반환한 실제 실행 화면

핵심 판단조건이 부족하면 재질문하고, 근거가 부족하면 답변을 중단
구현조건 추출 → temporal filter → hybrid retrieval → reranker → citation validation
검증636 tests · B0→H3 ablation · distractor corpus · 합성 회귀셋 70건
한계 공개법률 정답성·실사용자 효과 미측정, 로컬 추론 p50 62.9초
인사ON — 공개 인사 법령으로 도메인 특화 RAG·안전장치 검증 → 검색 계층 범용화 → PDF-to-Bot MCP — 임의 PDF를 Claude Code가 근거 기반으로 검색·답변

Python MCP SDK 기반 stdio 서버로 구현하고, Claude Code 연결·도구 노출·실제 호출까지 MCP Inspector로 검증했습니다.
