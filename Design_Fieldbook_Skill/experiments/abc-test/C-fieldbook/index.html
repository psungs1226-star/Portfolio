01 · ABOUT

5년 6개월의 공직 경험을 AI-native 실행 방식으로

인천광역시 중구청에서 사업기획, 예산·계약, 채용·급여, 공사·용역 감독과 유관기관 협의를 담당하며 복잡한 규정과 요구사항을 실행 가능한 업무로 구조화하는 능력을 길렀습니다.

2026년 4월 퇴직 이후, 이 역량에 AI 에이전트를 결합했습니다. 새로운 도메인의 자료를 빠르게 조사하고, 문제와 판단 기준을 정리해 제품·분석도구·자동화 시스템으로 구현하는 과정이 적성에 맞는다는 것을 확인했습니다.

PROBLEM-SOLVING PROCESS

이 4단계를 새로운 도메인마다 그대로 반복합니다. 산업 지식을 이미 안다고 가정하지 않고, 조사부터 검증까지 직접 수행합니다.

01 · 학습

도메인 자료를 AI로 조사하고, 근거를 사실·가정·모르는 것으로 분류합니다.

02 · 구조화

문제를 분해하고 사용자·리스크·의사결정 기준을 정의합니다.

03 · 구현

제품·프로토타입·에이전트·분석 파이프라인을 직접 만듭니다.

04 · 검증

테스트와 적대적 검증을 거쳐 결과와 한계를 함께 공개합니다.

학습 → 구조화 → 구현 → 검증. 도메인이 바뀌어도 이 흐름은 동일하게 적용됩니다.

02 · DOMAIN IMPACT

도메인이 달라져도 반복되는 문제 해결 구조

특정 산업을 이미 안다고 가정하지 않습니다. 사실·가정·모르는 것을 분리하고, AI가 만든 결과를 다시 검증할 구조까지 설계하는 것이 여러 도메인에서 일할 수 있는 기반이라고 생각합니다.

도메인해결한 문제 → 실행 결과

02소비자 금융 해외 ETF 적립의 직관성 부족과 판단 근거 부재기간·주기별 ETF 모으기 백테스트 + 모바일 웹 MVP

04세무 세법 개정 뒤 기존 판례·FAQ·해석례가 흔들릴 가능성고객 전달 전 검토 대상을 찾는 선제탐지 Tax Agent
