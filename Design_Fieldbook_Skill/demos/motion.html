모션 챕터 인터랙티브 데모

design-fieldbook 스킬의 references/motion.md에 정의된 duration·easing 토큰, 9종 패턴, 4-gate 필터, 슬롭 시그니처를 직접 조작하며 확인한다. 이 페이지 자체도 prefers-reduced-motion을 지킨다.

1. 이징 곡선 시각화

motion.md §3.2의 easing 토큰 5개. 곡선을 선택하고 재생하면 그 커브 그대로 공이 움직인다 — 그래프의 기울기가 급한 구간일수록 실제로도 빠르게 지나간다.

2. Duration 슬라이더

motion.md §3.1의 duration 16단계(50ms~1000ms). 슬라이더를 옮기면 같은 이동 거리를 그 duration으로 재생해 체감 속도를 비교한다.

3. 패턴 카탈로그 (9종)

motion.md 4절. 각 카드에서 Bad/Good을 토글하고 "실행"을 눌러 차이를 직접 본다.

4. 4-gate 필터 의사결정 트리

motion.md §6.4의 실제 워크스루: "카드에 hover 시 그림자가 커지며 3D로 살짝 기운다"에 4개 게이트를 순서대로 적용한다.

검토 대상: 카드 hover 시 그림자 확대 + 3D 기울임(perspective tilt)
GATE 1 · FREQUENCY

이 카드 그리드는 얼마나 자주 hover되는가? — 반복 노출이 잦지만, hover는 사용자의 의도적 동작이다.

GATE 2 · PURPOSE

이 모션은 상태 변화·공간 관계·주의 유도 중 무엇을 전달하는가?

GATE 3 · SPEED

§3 토큰표에서 이 요소에 맞는 duration·easing을 찾을 수 있는가?

GATE 4 · FUNCTION

prefers-reduced-motion·hover capability·60fps 규칙을 지키는가?
