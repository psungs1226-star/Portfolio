# 디자인 원칙

배치를 판단할 때 쓰는 13개 원칙과, 그 밑을 받치는 게슈탈트 지각 원리 7개. 출처: UI:UX Fieldbook `PRINCIPLES`/`GESTALT`.

각 원칙은 금지(실측 파라미터) → 필수(실측 파라미터)의 실제 구현 의도를 담는다. px/색상 값은 원본 데모의 실측치다 — 임의 예시가 아니다.

## 1. 시각 위계 (Visual Hierarchy)

중요한 것이 먼저 보이게 크기·두께·색으로 순서를 만든다. 랜딩 페이지의 첫 3초를 결정한다.

- **금지**: 제목/본문/버튼을 모두 18px/15px/14px 근처로 비슷하게 설정
- **필수**: 제목 36px/700 → 부제 17px/600 → 본문 15px, `max-width: 70%`(measure 제한)로 3단 위계. 본문 색은 `--ink-2`, Primary CTA만 진한 배경

## 2. 여백 (White Space)

요소 사이의 빈 공간. 여백이 정보의 소속과 중요도를 말해준다. 빼는 것이 더하는 것보다 어렵다.

- **금지**: 카드 내부 padding 14px, 카드 사이 gap 8px(내부보다 좁은 외부 간격)
- **필수**: 카드 내부 20px · 카드 사이 24px · 섹션 외곽 24px 3단계 여백. 카드 수는 4개→2개로 축소해 시각적 무게 집중

## 3. 대비 (Contrast)

차이를 명확히 드러내 눈에 띄게 만든다. 색·크기·질감 전부의 문제이며, 접근성의 첫 조건이다.

- **금지**: 배경(`#1A1A2E`) 위 텍스트 `#8B8BA6`(4.5:1 미달). 버튼-배경 대비 2.1:1
- **필수**: 제목 흰 텍스트(`#fff`)/검정 배경(`#0F0F1A`)로 21:1, 본문 `#B8B8CC`로 7:1(AAA). 버튼 대비 5.3:1 이상. CTA는 흰 글씨 기준 4.5:1을 넘는 그라데이션 단계(`#C43C00→#A83400`) 사용. **밝은 주황(`#FF4D00`)에 흰 글씨는 3.33:1로 미달**이니 그 위 텍스트는 반드시 더 어두운 단계를 쓴다(§color.md Painting vs Reading Color와 동일 원리)

## 4. 정렬 (Alignment)

요소를 공통된 기준선에 맞춘다. 눈이 따라갈 수 있는 질서를 만든다. 대시보드·폼에서 특히 중요하다.

- **금지**: 필드마다 라벨·인풋 높이를 다르게, 왼쪽 기준선을 들쑥날쑥하게 배치
- **필수**: 모든 필드를 "라벨 11px + 6px gap + 인풋 44px 높이"로 통일, 왼쪽 기준선 하나로 정렬(44px는 §a11y.md 터치 타겟 기준과 동일)

## 5. 균형 (Balance)

양쪽의 시각적 무게를 맞춘다. 대칭일 필요는 없고, 균형이면 된다. 히어로 레이아웃에서 빛을 발한다.

- **금지**: 왼쪽 텍스트(제목 32px)만 무겁게, 오른쪽은 단순 회색 박스로 배치
- **필수**: 텍스트(제목 36px Bold + 본문)의 무게 ≈ 비주얼의 무게로 맞춤. gap 32px→48px로 확대

## 6. 근접성 (Proximity)

가까이 있는 것끼리 한 그룹으로 묶인다. 거리가 관계를 말한다. 폼 필드 그룹핑의 핵심.

- **금지**: 6개 필드 전부를 동일 간격 12px로 배치(그룹 구분 없음)
- **필수**: Account(2필드)/Profile(2필드)로 분리, 그룹 내 12px · 그룹 간 24px. 그룹 라벨 + 배경 wash로 영역 시각화

## 7. 강조 (Emphasis)

한 가지를 두드러지게 해 나머지를 배경으로 만든다. CTA 계층 설계의 핵심.

- **금지**: 버튼 4개 전부를 동일한 Primary(진한 Fill) 스타일로 배치
- **필수**: Primary(Fill+Shadow) → Secondary(Outline) → Tertiary(텍스트만) → Ghost(연한 텍스트) 4단계로 구분

## 8. 반복 (Repetition)

같은 요소를 반복해 일관된 리듬과 단일 시스템을 만든다. 디자인 시스템의 기반.

- **금지**: 같은 역할(예: 저장 버튼)의 border-radius를 6/8/999px로 제각각 적용
- **필수**: Primary/Secondary/Tertiary 3타입만 존재, radius 8px로 통일

## 9. 일관성 (Consistency)

같은 의미는 항상 같은 방식으로 표현한다. 예측 가능한 제품의 기반이며 신뢰를 만든다.

- **금지**: 제목 컴포넌트를 화면마다 배경·padding·radius가 다르게 구현(변형 난립)
- **필수**: 제목 컴포넌트 1개로 통일(`--bg-2` 배경 + `--line-2` 보더 + 16px padding + 8px radius)

## 10. 스케일 (Scale)

크기 차이로 중요도를 드러낸다. 제목이 본문보다 커야 하는 이유가 있어야 한다.

- **금지**: 카드 안 제목·라벨·핵심 수치를 전부 12px로 통일(스케일 차등 0단계)
- **필수**: 제목/핵심 수치 20px → 보조 수치 16px → 라벨·캡션 10–12px 4단계 스케일

## 11. 리듬 (Rhythm)

간격과 반복의 패턴이 시선을 움직이는 속도를 만든다. 읽기 좋은 페이지는 리듬이 있다.

- **금지**: 리스트 항목 간 간격을 4px/22px/30px처럼 제멋대로 적용
- **필수**: 항목 간 간격 16px(8px baseline grid 배수)로 균등화, 모바일 12px로 축소

## 12. 대칭 (Symmetry)

좌우가 거울처럼 맞닿는 배치. 안정과 격식을 준다. 브랜드·공식 페이지에 적합.

- **금지**: 좌우 동일 크기 카드를 한쪽만 24px 아래로 밀어 배치
- **필수**: 좌우 카드의 크기·위치를 완전히 일치("equal size · equal distance · stable")

## 13. 비대칭 (Asymmetry)

대칭을 깨되 무게는 유지한다. 생동감과 현대적 느낌을 준다. 편집·포트폴리오에 강하다.

- **금지**: 두 박스를 같은 중심선 위에 세로로만 쌓아 배치("no focal direction")
- **필수**: 큰 앵커 카드(약 57%×51%, 좌상단) + 작은 액센트 카드(약 26%×24%, 우하단)로 대각선 무게중심 구성("large anchor + small accent = dynamic balance")

> 금지: 13개 원칙을 전부 "적당히 지키는" 것 — 예: 모든 섹션에 동일한 24px 여백·동일한 카드 그림자를 기계적으로 적용(반복·일관성은 지켜도 강조·위계가 실종). 원칙은 서로 상충할 수 있고, 그 상충을 의도적으로 조율하는 것이 디자인이다.

## 게슈탈트 7원리

배치가 "왜 그렇게 지각되는가"를 설명하는 지각 심리학 원리. 13원칙의 근거층이다.

| 원리 | 정의 |
|---|---|
| 근접성(Proximity) | 가까운 것은 하나의 그룹으로 보인다 — 거리가 관계다 |
| 유사성(Similarity) | 비슷한 색·모양·크기는 같은 부류로 묶인다 |
| 폐쇄성(Closure) | 빠진 부분을 눈이 스스로 채워 완성된 형태로 본다 |
| 연속성(Continuation) | 중간이 가려져도 시선이 이어지는 경로를 따라간다 |
| 전경/배경(Figure/Ground) | 눈은 한 순간에 하나의 형상을 인식한다 — 그 형상이 배경이 되기도 한다 |
| 공통 영역(Common Region) | 같은 테두리·배경 안에 있으면 한 그룹으로 묶인다 |
| 공동 운명(Common Fate) | 같은 방향으로 움직이는 것은 한 단위로 묶여 보인다 — §motion.md 2.5 연출(choreography)의 근거이기도 하다 |

**적용 예**: 근접성은 원칙 6(근접성)과 직결. 공통 영역은 원칙 6의 "배경 wash로 그룹 영역 시각화"와 같은 기법. 공동 운명은 정적 레이아웃 원칙이 아니라 모션에서만 성립하는 유일한 게슈탈트 원리 — 리스트 아이템이 함께 슬라이드되면 한 그룹으로 지각된다.
