# 스타일 상세 — Emotion (7)

`references/styles.md` 인덱스의 Emotion 카테고리 상세. 이 카테고리는 금지 스타일이 없다.

**DNA 8축 순서**: type · space · contrast · border · round · shadow · color · deco (각 0–5)
**계보에서 금지 스타일 7종은 제거했다** — 계보는 "다음 후보로 뭘 볼까"를 위한 데이터인데 금지 스타일은 후보가 될 수 없어서다. 태그→카테고리 매핑은 `references/styles.md` 인덱스를 본다.

**레시피의 색 표기는 팔레트가 아니라 색 관계다** — `Purple / pink` 같은 표기는 "이 두 색을 쓰라"가 아니라 "보라→핑크로 이어지는 인접 색상 그라데이션"이라는 관계다. 실제 색은 프로젝트 브랜드에서 정하고 관계만 재현한다.

### 23. Retro Web 레트로 웹 — `retro`
**태그라인**: 90년대 인터넷의 온기. 베이지와 갈색, 그리고 구식 창문. **정의**: 1990~2000년대 초의 웹 미학. 크림색 배경, 갈색 톤, 테이블 레이아웃, 구식 브라우저 요소로 노스탤지어를 만든다. **특징**: Warm Tones, Old Web Texture, Window Frames, Nostalgia
**사례**: Windows 93(https://www.windows93.net) — 구식 OS의 사운드와 창문을 웹으로 완벽 재현 · Craigslist(https://www.craigslist.org) — 20년 넘게 형태가 거의 변하지 않은 원시 웹의 생존자
**DNA**: type3 space3 contrast2 border3 round0 shadow1 color2 deco4
**레시피**: type `System sans` / color `Beige / brown` / layout `Window frames` / border `2px` / radius `4px` / spacing `Tight` / motion `Instant`
**계보**: Related: y2k,frutiger,brutal / Influenced: y2k / Confused: y2k / Opposite: glass
**관찰**: 크림·갈색 톤의 온기 · 구식 창문·테두리 요소 · 픽셀·보더가 "시간 여행" 장치인지 · 의도적으로 배치된 노스탤지어 · 낡아 보이는 것에는 기억의 온도가 있다
**키워드**: 레트로, 90년대, 올드웹, 윈도우93, 노스탤지어, 구식, 복고, 베이지

### 24. Y2K — `y2k`
**태그라인**: 크롬과 거품이 가득한, 2000년대가 꿈꾸던 미래. **정의**: 2000년 전후의 낙관적 미래상. 크롬 메탈, 광택, 거품, 형광색으로 "새로운 밀레니엄"의 설렘을 표현. **특징**: Chrome & Metal, Gloss & Bubbles, Futuristic Optimism, Bold
**사례**: Space Jam(https://www.spacejam.com) — 1996년 그대로 남아 있는 인터넷 초기의 유물 · Wayback Machine(https://web.archive.org) — 당시 Y2K 스타일 사이트를 직접 열람
**DNA**: type3 space3 contrast3 border2 round4 shadow4 color5 deco5
**레시피**: type `Sans · techno` / color `Chrome & cyan` / layout `Bevelled boxes` / border `Silver 2px` / radius `12px` / spacing `Bubbly` / motion `Shine`
**계보**: Related: frutiger,retro,vaporwave / Influenced By: skeuo,retro / Influenced: vaporwave / Confused: frutiger / Opposite: brutal
**관찰**: 크롬·메탈 그라데이션이 미래를 표현하는지 · 거품·광택 하이라이트 · 형광색+메탈릭의 결합 · "과거의 미래"를 오늘의 시선으로 보기
**키워드**: y2k, 2000년대, 크롬, 거품, 미래, 메탈릭, 광택

### 25. Cyberpunk 사이버펑크 — `cyberpunk`
**태그라인**: 네온이 터지는 디스토피아. 글리치와 광고 홀로그램. **정의**: 고도의 테크놀로지와 몰락한 사회를 그린 장르의 시각. 네온(사이언·마젠타), 어두운 배경, 글리치 텍스트, 사각형 UI. **특징**: Neon & Glow, Dark Dystopia, Glitch Effect, HUD Panels
**사례**: Cyberpunk 2077(https://www.cyberpunk.net) — 브랜드 자체가 네온 디스토피아 세계관 · Sci-Fi Interfaces(https://scifiinterfaces.com) — 영화·게임 속 SF UI 아카이브
**DNA**: type5 space2 contrast5 border2 round1 shadow5 color5 deco5
**레시피**: type `Display · techno` / color `Cyan / magenta neon` / layout `HUD panels` / border `1.5px neon` / radius `4px` / spacing `Dense` / motion `Glitch`
**계보**: Related: vaporwave,acid,brutal / Influenced By: brutal / Confused: vaporwave / Opposite: scandi
**관찰**: 네온이 배경과 분리되는 대비 · 글로우 효과 · HUD 패널이 정보 밀도를 높이는지 · 글리치 텍스트의 장르감
**키워드**: 사이버펑크, 네온, 글리치, 디스토피아, 네온사인, sf, SF, 과학

### 26. Vaporwave 베이퍼웨이브 — `vaporwave`
**태그라인**: 보라와 핑크의 노스탤지어. 가상의 과거, 이상적인 80년대. **정의**: 2010년대 초 인터넷 음악 장르에서 시작된 미학. 그리스 조각, 일본어 문자, 3D 격자, 석양, 보라·핑크 그라데이션. **특징**: Purple & Pink, Grid & Retro Sun, Nostalgic Futurism, ASCII & Japanese
**사례**: Vapor95(https://vapor95.com) — 사이트 자체가 베이퍼웨이브, 네온·그리드·로마 조각상을 실제 커머스에 적용 · SoundCloud(https://soundcloud.com) — 베이퍼웨이브 씬이 시작된 음악 플랫폼
**DNA**: type3 space3 contrast3 border1 round2 shadow2 color5 deco5
**레시피**: type `Retro future` / color `Purple / pink` / layout `Centered` / border `None` / radius `8px` / spacing `Dreamy` / motion `Glow`
**계보**: Related: cyberpunk,y2k,acid / Influenced By: y2k,memphis / Confused: cyberpunk
**관찰**: 보라·핑크 그라데이션의 꿈결 · 그리스 조각·격자·석양 모티프 · 고전과 미래의 충돌(핵심) · 일본어 문자·ASCII의 장식적 사용
**키워드**: 베이퍼웨이브, 보라, 핑크, 노스탤지어, aesthetic, 80년대, 꿈

### 27. Scandinavian 스칸디나비아 — `scandi`
**태그라인**: 빛, 나무, 그리고 따뜻한 최소함. **정의**: 북유럽 디자인의 온건한 미니멀리즘. 밝은 톤의 나무 질감, 세이지·파스텔 컬러, 기능 중심 배치로 포근하고 실용적인 분위기. **특징**: Light & Airy, Natural Materials, Function, Hygge Warmth
**사례**: IKEA(https://www.ikea.com) — 스칸디나비아 디자인을 세계에 대중화 · Muuto(https://www.muuto.com) — 북유럽 브랜드의 컬러·소재 미학
**DNA**: type3 space5 contrast2 border0 round1 shadow0 color2 deco1
**레시피**: type `Sans` / color `Sage / pastel` / layout `Warm minimal` / border `None` / radius `8px` / spacing `Airy` / motion `Gentle`
**계보**: Related: jpminimal / Influenced By: jpminimal / Confused: jpminimal / Opposite: brutal,cyberpunk
**관찰**: 밝은 배경+나무 질감이 실내 온도를 올리는지 · 세이지·파스텔 톤의 차분함 · 자연스러운 기능 중심 배치 · "따뜻하게 비우는" 미니멀리즘
**키워드**: 스칸디, 북유럽, 나무, 따뜻, 이케아, hygge, 세이지

> **주의**: 절제·저채도 계열이라 방향을 느슨하게 잡으면 금지 스타일(`minimal`)이 만들어내는 "무난한 회색 UI"로 흘러가기 쉽다. 채택한다면 세이지/나무 같은 **온도 있는 색**과 자연 소재 질감을 반드시 넣어 차별화한다.

### 28. Japanese Minimalism 일본 미니멀리즘 — `jpminimal`
**태그라인**: 여백(間, Ma)과 침묵. 없는 것이 의미가 되는 디자인. **정의**: 일본 미학(間, 侘寂)에 뿌리를 둔 디자인. 넓은 여백, 단일 포인트 색, 절제된 타이포로 정적이고 깊은 분위기. **특징**: Empty Space (Ma), Single Accent, Silence, Zen & Nature
**사례**: MUJI(https://www.muji.com) — 여백과 간소함 자체가 브랜드가 된 대표 사례 · SSENSE(https://www.ssense.com) — 하이패션 미니멀리즘의 정적인 카탈로그
**DNA**: type4 space5 contrast2 border0 round0 shadow0 color1 deco0
**레시피**: type `Mincho serif` / color `Off-white · one red` / layout `Vast margin` / border `Hairline` / radius `0` / spacing `Extreme` / motion `Slow fade`
**계보**: Related: scandi / Influenced: scandi / Confused: scandi / Opposite: acid,cyberpunk
**관찰**: 여백(間)이 공허가 아니라 의도인지 · 포인트 색 하나가 화면 의미를 정하는지 · 정적인 타이포가 만드는 침묵 · 불완전함에서 아름다움을 보는 와비사비의 태도
**키워드**: 일본, 와비사비, 여백, ma, 간, 정적, 미니멀, 일본미니멀, 마

> **주의**: `scandi`와 같은 이유로 "무난한 회색 UI"로 흘러갈 위험이 있다. 이 스타일을 채택한다면 **여백을 극단(space5)으로 밀고**(어중간한 여백은 그냥 빈 화면이다), 명조(Mincho) 계열 세리프와 포인트 색 정확히 1개라는 두 조건을 지켜야 한다.

### 29. Acid Graphics 애시드 그래픽 — `acid`
**태그라인**: 레이브의 색, 흐르는 무지개, 반짝이는 PVC. **정의**: 1990년대 레이브 문화에서 시작된 그래픽 스타일. 네온 원색, 무지개 그라데이션, 글리치·립스틱 질감으로 장난스럽고 과감하다. **특징**: Vivid Neons, Rainbow Gradient, PVC Gloss, Anti-design
**사례**: Boiler Room(https://boilerroom.tv) — 레이브 문화와 강렬한 비주얼을 잇는 플랫폼 · Beatport(https://www.beatport.com) — 전자음악의 에너지를 컬러로 표현한 상점
**DNA**: type4 space3 contrast5 border2 round2 shadow1 color5 deco5
**레시피**: type `Display · loud` / color `Rainbow neon` / layout `Anti-design` / border `2px black` / radius `4px` / spacing `Charged` / motion `Distort`
**계보**: Related: corp-memphis,memphis,cyberpunk,vaporwave / Influenced By: memphis / Influenced: neobrutal / Confused: vaporwave,neobrutal / Opposite: luxury
**관찰**: 네온 원색이 겹치되 서로 덮지 않는지 · 무지개 그라데이션·PVC 광택 · "질서 밖" 감성을 만드는 기하·글리치 · 반디자인(anti-design)의 의도
**키워드**: 애시드, 네온, 무지개, 레이브, pvc, 반디자인, 역디자인
