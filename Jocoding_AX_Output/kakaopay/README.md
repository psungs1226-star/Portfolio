# 카카오페이증권 — 해외 ETF 모으기 백테스트 UX

경쟁 서비스인 토스와 비교했을 때 카카오페이증권의 주식 모으기 경험이 상대적으로 직관적이지 않다는 문제의식에서 출발한 Codex 플러그인과 모바일 웹 MVP입니다.

## 문제와 판단

카카오페이증권과 토스는 주식 모으기 영역의 주요 서비스입니다. 두 서비스를 비교했을 때 카카오페이증권은 초보 투자자가 적립 결과를 이해하는 과정의 직관성이 상대적으로 약하다고 판단했습니다. 해외 ETF를 처음 모으는 사용자도 종목명과 현재 가격만 보는 것이 아니라, **얼마를 어떤 주기로 얼마나 오래 모았을 때 과거에는 어떤 결과가 나왔는지** 바로 확인할 수 있어야 한다고 봤습니다.

제품 구상은 1·3·5·10년의 기간과 매일·매주·매월의 적립 주기, 투자 금액을 조합해 비교하는 백테스트입니다. 이번 공개 MVP에서는 다음 범위를 우선 구현했습니다.

- 3·5·10년 투자 기간 비교
- 매일 모으기와 적립금액 선택
- 적립금액에 따른 누적 투자금과 과거 결과 분포 계산
- 여러 과거 시작점의 최저·평균·최고 범위를 함께 제시
- 기간, 환율, 배당, 데이터 출처와 표본 한계 표시
- 초보 투자자가 모바일 화면에서 조건을 바꾸며 바로 비교할 수 있는 UX

1년 및 매주·매월 모으기 비교는 동일한 계산 구조를 활용한 후속 확장 범위입니다.

결과는 미래 수익률 예측이나 ETF 추천이 아니라, 과거 데이터에서 적립 조건별 결과가 어떻게 달라졌는지 확인하는 백테스트 참고자료로 제한했습니다.

## 검증 관점

로컬 fixture를 사용해 계산과 화면을 재현하며, 상장 이력이 짧아 표본이 없는 ETF에는 10년과 같은 미지원 기간을 노출하지 않습니다. 구현된 기간·금액을 바꿀 때 계산과 설명이 함께 갱신되는지 검증했고, 결과 문구가 추천이나 미래 보장처럼 읽히지 않도록 제한했습니다.
