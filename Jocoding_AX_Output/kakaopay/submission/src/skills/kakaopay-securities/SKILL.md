# 카카오페이증권 ETF 리스크 설명 UX 스킬

## 목적

이 스킬은 카카오페이증권의 해외 ETF 모으기 설명 화면, 고객 안내 초안, README 문구, 제출 답변 초안을 점검해 과거 수익률 분포를 앞으로의 참고 범위로 보여줄 때 미래 성과 보장처럼 읽히지 않도록 돕는다.

스킬의 산출물은 투자 판단, 주문, 세무 신고, 계좌 개설을 대신하지 않는다. 사용자가 준 화면이나 문서를 리스크 우선 설명 UX 기준으로 분석하고, 필요한 경우 더 안전한 구조와 문구를 제안한다.

## 사용해야 하는 상황

- 해외 ETF 모으기, 주식 모으기, 소수점 해외주식 설명 화면을 검토할 때
- 과거 3년·5년·10년 일별 시작점 수익률 분포 화면이 수익 강조형으로 보이는지 점검할 때
- SCHD, QQQM, VOO 같은 ETF 데이터가 상품 권유처럼 읽히지 않는지 확인할 때
- README, 제출 답변, 웹 MVP 문구가 같은 문제 정의를 말하는지 맞출 때
- 환율과 배당 재투자 가정이 화면에서 누락됐는지 볼 때

## 입력

가능한 입력은 아래 중 하나 이상이다.

- 앱 화면 문구 또는 컴포넌트 코드
- README 또는 제출 답변 초안
- 시뮬레이션 결과 요약
- 분석 조건: 분석 대상 ETF, 적립 금액, 기간, 표시 통화, 환율, 배당 가정
- 공개 근거 또는 내부 조사 문서 경로

입력이 부족하면 부족한 항목을 `확인 필요`로 남기고, 없는 정보를 꾸며 쓰지 않는다.

## 판단 기준

1. 대상 기업은 카카오페이증권 하나로 유지한다.
2. 문제 정의는 해외 ETF 모으기 확장, 초보 사용자 이해, 금융소비자보호 맥락과 연결한다.
3. 결과는 항상 `과거 수익률로 잡아본 범위 · 보장 아님` 의미를 먼저 드러낸다.
4. 평균만이 아니라 과거 최저치와 과거 최고치를 함께 보이게 한다.
5. ETF는 `분석 대상 ETF`, `고정 예시 데이터`, `검증 데이터`로만 표현한다.
6. 데이터 출처, 데이터 기간, 환율과 배당 재투자 가정은 결과 근처에서 확인 가능해야 한다.
7. 실시간 API, 개인 계좌정보, API 키, 주문 실행, 세무 대리 기능을 요구하지 않는다.

## 금지 표현과 대체 방향

아래 표현은 제품 주장, CTA, 결과 라벨, 사용자 행동 유도 문구에서 쓰지 않는다. 단, 금지 목록을 설명하기 위해 인용하는 것은 가능하다.

| 피할 표현 | 대체 방향 |
|---|---|
| 예상 수익률 | 과거 구간 결과 |
| 95% 확률 | 과거 결과 범위 |
| 추천 | 분석 대상 또는 예시 |
| 안정적 | 변동이 작았던 과거 구간 |
| 초보자에게 적합 | 이해하기 쉬운 설명 |
| 장기적으로 유리 | 과거 조건에서 달라진 결과 |

주문, 매수, 가입, 선택 완료처럼 금융 실행을 떠올리게 하는 CTA도 피한다. CTA는 `분석 조건 확인`, `가정 보기`, `결과 범위 보기`, `그래프 자세히 보기`, `입력 다시 확인`처럼 확인형으로 쓴다.

## 작업 절차

1. 입력의 목적과 대상 사용자를 확인한다.
2. 카카오페이증권, 해외 ETF 모으기, 초보 사용자 리스크 설명 문제와 연결되는지 확인한다.
3. 화면 또는 문서에서 성과 약속, 상품 권유, 투자 실행 유도처럼 보이는 표현을 찾는다.
4. 결과 표시 순서를 점검한다.
5. 누락된 가정과 한계를 정리한다.
6. 필요한 경우 더 안전한 문구와 화면 구조를 제안한다.
7. 검증 방법을 함께 남긴다.

## 출력 형식

기본 출력은 아래 구조를 따른다.

```markdown
## 점검 결과

- 통과:
- 수정 필요:
- 확인 필요:

## 수정 제안

- 화면 구조:
- 문구:
- 가정과 한계:

## 검증 방법

- 금지 표현 검색:
- 웹 MVP 빌드:
- 계산 테스트:
```

문서 초안을 바로 작성해 달라는 요청이면 위 구조 대신 README, 제출 답변, 화면 문구 형식에 맞춰 작성한다. 그래도 마지막에는 검증 방법과 남은 한계를 짧게 남긴다.

## 웹 MVP 연결

이 제출물의 웹 MVP는 `web/` 폴더에 있으며, SCHD 고정 예시 데이터와 QQQM, VOO 검증 데이터를 사용해 과거 3년·5년·10년 일별 시작점 수익률 분포를 만들고 선택한 하루 금액과 기간의 참고 범위를 보여준다. QQQM처럼 데이터 기간이 부족한 경우 10년 참고 범위는 표시하지 않는다.

웹 MVP는 스킬의 판단 기준을 실제 화면으로 보여주는 예시다. 스킬은 웹 MVP를 운영 서비스로 간주하지 않고, 설명 UX와 문구 원칙을 검토하는 기준으로 사용한다.

## 보안 원칙

- API 키, 비밀번호, 토큰, 계좌번호, 주민등록번호, 실제 거래내역 원본을 요청하지 않는다.
- 사용자가 민감정보가 포함된 입력을 주면 분석 전에 제거해야 할 항목을 먼저 알린다.
- 숫자 결과는 사용자가 제공한 가정, 로컬 고정 예시 데이터, 출처가 남은 검증 데이터에서만 나온 것으로 표시한다.
