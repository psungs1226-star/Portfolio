## 운영 규칙

- 이 파일은 제출 폼 본문2의 5개 문항과 산출물 준비 과정을 추적한다.
- 문항 관련 작업, 판단, 검증, AI 활용 내용이 생기면 아래 `Append Log` 섹션에 요약을 추가한다.
- 기존 기록은 수정하거나 삭제하지 않는다. 변경이 필요하면 새 항목을 append한다.
- API 키, 비밀번호, 토큰 등 비밀정보는 이 파일과 대화 로그에 남기지 않는다.

## 과제 파악 요약

- 공식 페이지: https://hackathon.jocodingax.ai/
- 일정: 서류 접수 및 온라인 예선 과제 제출은 2026-06-23부터 2026-07-10까지, 본선자 발표는 2026-07-15, 오프라인 본선은 2026-07-18 당산역 워크모어 11F.
- 예선 과제: 선택한 단일 기업, 그 산업, 또는 고객이 겪는 공개·검증 가능한 실제 문제를 정의하고 이를 해결하는 Codex 플러그인을 제출한다.
- 제출물: `submission.zip` 안에 `src/`, `README.md`, `logs/`가 있어야 하며, 플러그인 루트 전체는 `src/` 안에 있어야 한다.
- 필수 파일: `src/.codex-plugin/plugin.json`.
- 플러그인 구성: `plugin.json` 외에 실제 동작 요소가 하나 이상 필요하다. 일반적으로 `skills/<name>/SKILL.md`를 포함하고, 필요하면 `.mcp.json` 또는 실행 코드를 둔다.
- 로그: AI와 주고받은 전체 대화 로그를 편집·발췌 없이 `logs/`에 제출한다. 가능한 형식은 `md`, `txt`, `json`, `jsonl`.
- 평가 관점: 공개 자료로 입증되는 문제 정의, 기업/산업 맥락 적합성, 실제 동작하는 Codex 플러그인, AI 활용 과정과 검증의 정합성.
- 주의: 여러 기업을 다루면 기업별 플러그인을 별도 제출해야 하며, 하나의 제출물로 여러 기업을 함께 다룰 수 없다.

#### 문항 3 최종 초안 v3. 플러그인은 어떻게 작동하나요? (1000자)

플러그인은 `plugin.json`과 `kakaopay-securities` 스킬로 구성됩니다. 사용자가 해외 ETF 모으기 화면 문구, 코드, README, 결과 요약을 주면 먼저 대상이 카카오페이증권과 해외 ETF 모으기 맥락에 맞는지 확인합니다. 이어서 결과가 성과 약속처럼 읽히는 표현, 단일 수익률만 강조하는 구조, 누락된 가정을 찾습니다. 점검 결과는 통과·수정 필요·확인 필요로 나누고, 필요한 경우 결과 표시 순서와 문구를 제안합니다. 정보가 없으면 값을 만들어 넣지 않고 `확인 필요`로 남깁니다.

QQQM은 2020년 상장으로 10년 표본이 부족해 3년과 5년만 제공한다. 조정종가를 쓰는 QQQM·VOO에는 배당률을 별도로 더하지 않으며, 웹 MVP 실행 중에는 외부 API를 호출하지 않는다.

#### 문항 5 최종 초안 v3. 어떻게 검증했나요? (800자)

정상 흐름은 QQQM 또는 VOO를 선택하고 기간과 하루 적립 금액을 바꾸었을 때, 그래프·원금·과거 최저치·평균·최고치·가정 문구가 같은 계산 결과를 쓰는지 확인하는 방식입니다. QQQM은 3년과 5년만, VOO는 3년·5년·10년을 제공하는지 확인했습니다. 예외 흐름으로는 VOO의 10년을 본 뒤 QQQM으로 바꿔도 화면과 계산이 5년으로 즉시 맞춰지는지, 조정종가 데이터에 SCHD용 배당·stress 가정이 섞이지 않는지 확인했습니다.

`npm run fetch:fixtures`로 QQQM·VOO·USD/KRW snapshot을 갱신한 뒤 `npm test`를 실행해 7개 계산 테스트를 통과시켰고, `npm run build`로 웹 빌드를 확인했습니다. `validate_plugin.py submission/src`로 manifest와 스킬 구조도 검증했습니다. 금지 표현 검색으로 성과 약속이나 상품 권유로 읽힐 문구가 화면·CTA·결과 라벨에 없는지 확인했습니다. 한계도 남아 있습니다. 데이터는 제출 검증용 로컬 snapshot이며 실시간 시세나 실제 주문 결과가 아니고, 개인 계좌·세금·수수료 조건은 계산하지 않습니다.
