# PRD: 해외 ETF 모으기 리스크 설명 UX

## 목적

카카오페이증권의 해외 ETF 모으기 사용자가 과거 적립 결과를 성과 약속처럼 받아들이지 않도록, 과거 데이터 기반 결과 범위와 불리한 구간을 먼저 보여주는 모바일 앱형 UX를 만든다.

## 대상 사용자

- 카카오페이증권의 해외주식 또는 주식 모으기 경험을 확장하는 사용자
- 과거 성과 숫자, 환율, 비용, 세금의 의미를 한 화면에서 이해하기 어려운 사용자
- 제출물 설명상 직접 사용자는 카카오페이증권의 상품, UX, 고객경험, 금융소비자보호 관련 실무자로 둔다.

## 사용자 문제

해외 ETF 모으기는 소액, 반복, 장기 흐름으로 접근하기 쉽다. 그러나 과거 수익률이나 누적 결과가 단일 숫자로 제시되면 사용자는 손실 가능성, 원금 하회 기간, 환율과 비용의 영향을 충분히 보지 못할 수 있다.

이 MVP는 투자 결정을 대신하지 않고, 같은 적립 조건에서도 과거 구간별 결과가 달라졌다는 점을 설명한다.

## MVP 목표

- 모바일 첫 화면에서 분석 조건을 간단히 확인한다.
- 결과 첫 화면에서 불리한 사례, 최대낙폭, 비용 영향을 먼저 이해시킨다.
- 그래프는 원금 대비 평가금액, 과거 결과 범위, 비용 영향 비교로 제한한다.
- 모든 결과는 과거 데이터와 명시된 가정에 묶어서 설명한다.

## 제외 범위

- 종목 매수, 매도, 보유 판단 제공
- 특정 ETF 홍보
- 실시간 시세 연동
- 개인 투자정보 수집
- 세무 신고, 주문, 계좌 개설 자동화
- 카카오페이증권 내부 시스템 연동

## 기본 시나리오

- 분석 대상 ETF: SCHD 고정 예시 데이터
- 적립 금액: 매일 5,000원
- 기간: 5년
- 표시 기준: 원화 기준
- 고급 설정: 환율, 수수료, 세금, 배당 재투자 가정

## UX 원칙

- 첫 화면은 한 가지 행동만 강조한다: 분석 조건 확인.
- 최고 결과보다 불리한 결과와 손실 구간을 먼저 보여준다.
- 통계 용어는 기본 화면에서 줄이고, 상세 통계는 접힌 영역으로 둔다.
- CTA는 투자 실행처럼 보이면 안 된다.
- 모바일 390px 폭에서 텍스트와 그래프가 겹치지 않아야 한다.

## 사용자에게 보이는 문구 규칙

- SCHD는 `분석 대상 ETF` 또는 `고정 예시 데이터`로 표현한다.
- 결과에는 `과거 시뮬레이션 · 미래 성과 아님` 라벨을 둔다.
- 수익 강조형 문구, 확률 보장형 문구, 특정 상품 권유형 문구는 쓰지 않는다.

## PRD 인수 기준

- 문제 정의가 카카오페이증권의 해외주식, 주식 모으기, 소비자보호 맥락과 연결된다.
- 구현 범위가 웹 MVP와 Codex 플러그인 설명으로 제한된다.
- 투자 조언이나 성과 약속으로 읽힐 표현을 배제한다.
