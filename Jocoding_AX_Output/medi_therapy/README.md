# 메디테라피 — 인플루언서 시딩 의사결정

메디테라피의 실제 과제인 인플루언서 시딩에서, 신제품과 진정성 있게 맞는 인플루언서를 찾기 위해 제품·피부 특성·콘텐츠 성향을 연결한 의사결정 시스템입니다.

## 문제와 판단

팔로워 수가 많은 인플루언서를 우선하는 방식보다 **평소 다루는 피부 고민과 화장품 특성이 신제품과 얼마나 자연스럽게 맞는지**가 더 중요하다고 봤습니다.

- 인플루언서의 공개 정보를 수집하고 콘텐츠·피부 특성·선호 제품을 분류
- 건성·지성 등 피부 타입과 주로 다루는 화장품 기능을 구조화
- 신제품의 효능·사용 맥락·타깃 피부 고민과 인플루언서 특성을 매칭
- 실제 사용 경험처럼 진정성 있게 전달될 가능성을 기준으로 후보 랭킹
- 의료·시술·과장 표현 위험은 점수 계산 전에 hard exclusion
- 공개 조회수·댓글과 내부 클릭·쿠폰·주문 데이터를 구분
- 데이터가 부족하면 `needs_more_data`, 검토가 필요하면 `review_required`로 표시

## 검증 관점

신제품을 입력하면 제품 특성과 맞는 후보를 다시 랭킹하고, 피부 고민 매칭·평소 콘텐츠 맥락·선정 이유·표현 리스크·관찰 KPI를 함께 생성합니다. 시딩 이후에는 어떤 조합이 진정성 있는 반응으로 이어졌는지 학습할 수 있게 설계했으며, 실제 매출·ROAS는 공개 데이터만으로 단정하지 않습니다.

상위 비교는 [AX 기업 문제 해결 3건](../)에서 확인할 수 있습니다.
