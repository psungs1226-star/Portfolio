# AX 인재전쟁 - 메디테라피 지원 목표

## 목표

메디테라피를 대상으로, 공개 자료로 확인 가능한 실제 문제인 "매출로 이어지는 인플루언서 시딩 시스템 설계"를 Codex 플러그인으로 해결한다.

플러그인은 뷰티/소비재 마케터가 인플루언서 후보, 콘텐츠 맥락, 제품 적합성, 예상 매출 기여 가설을 구조화하고, 온톨로지 -> 인과관계 가설 -> 반복 가능한 실행 루프 순서로 시딩 전략을 설계하도록 돕는 방향으로 만든다.

## 판단 기준

- 해커톤 과제 요구사항: 선택 기업의 공개/검증 가능한 문제를 해결하는 Codex 플러그인을 제출한다.
- 메디테라피 영상 핵심: AX는 단순 자동화가 아니라 시스템이 판단하고, 그 판단이 매출로 이어졌음을 증명하며, 반복적으로 더 똑똑해지는 과정이다.
- 메디테라피가 보는 핵심 역량: 문제 정의 능력, 온톨로지 구축, 인과관계 추정, 반복 가능한 루프 설계, 인간의 창발성.
- 제출물은 `submission.zip` 안에 `src/.codex-plugin/plugin.json`, `src/skills/<name>/SKILL.md`, README, logs를 포함해야 한다.
