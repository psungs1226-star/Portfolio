부가가치세 개정 영향 탐지 스킬 아키텍처

법령 변경을 입력하면 기존 집행기준 중 변경 영향 가능성이 높은 항목을 우선순위로 뽑아 내부용 변경 예상 검토리스트로 전환하는 MVP 설계입니다. 해석례는 세법해석정비 정답셋과 보조 판단 사례로만 사용합니다.

MVP: 부가가치세 대상: 영세사업자 데이터: 집행기준 중심 판단: 전문가 검토 연결
범위 흐름 스킬 데이터 파싱 분류 검증 대회 범위

핵심 판단

이번 대회에서는 전체 세법 자동화를 목표로 잡지 않습니다. 부가가치세 1개 세목에서 집행기준의 변경 영향 가능성을 찾고, 해석례는 정답셋과 보조 판단 사례로만 쓰는 작은 파이프라인을 만드는 것이 적합합니다.

작게 구현 근거 중심 검증 가능

제외할 것

  • 모든 세목과 모든 자료를 수집하는 범용 세법 AI
  • 판례 전체 수집(sweep corpus) 및 자동 법률 판단 · 결론 단정
  • 납세자에게 유리/불리한 결론 단정
  • 실제 신고 의사결정 자동화

단, 판례를 전체 수집하지 않을 뿐 — 심판례(조세심판원)는 좁은 불안정 "신호"(L2), 대법원 판례는 사후 "검증자"(L3)로 한정 사용한다(sweep 코퍼스도 아니고 자동 단정도 아님). 즉 "판례 전체 수집·자동판단 제외"와 "심판례를 좁은 신호로 사용"은 모순이 아니라 정확히 위 제외선을 지키는 설계다.

전체 처리 흐름

법령 변경 입력을 기준으로 기존 세무 기준문서와 매칭하고, 영향 가능성과 검토 우선순위를 산출합니다.

01법령 변경 입력
02조문·요건 파싱
03집행기준 우선 검색
04영향 유형 분류
05검토 리스트 생성
06Agent 가드레일 적용

스킬별 아키텍처

Skill 1

법령 변경 입력 정규화

개정 법령, 신구조문대비표, 시행일, 적용례를 구조화합니다.

  • 조문번호, 변경 전후 문구 추출
  • 신설/삭제/요건변경/기준금액변경 분류
  • 시행일과 경과조치 분리

출력

세목, 조문, 변경 유형, 적용 대상, 핵심 용어, 시행일을 담은 JSON 객체

Skill 2

기준문서 수집·인덱싱

집행기준을 검색 가능한 단위로 저장하고, 해석례는 세법해석정비 정답셋과 보조 판단 사례로만 저장합니다.

  • 문서번호, 생산일자, 관련 조문
  • 질의·회신·판단요지 분리
  • 키워드 검색과 벡터 검색 동시 구성

출력

문서 청크, 메타데이터, 쟁점 태그, 납세자 태그, 검색 인덱스

Skill 3

영향 후보 탐색

변경 조문과 기존 문서를 매칭해 영향 가능성이 있는 후보를 뽑습니다.

  • 조문 직접 매칭
  • 키워드·요건·거래유형 매칭
  • 의미 검색 기반 관련 문서 탐색

출력

영향 유형, 점수, 신뢰도, 매칭 근거, 전문가 검토 필요 여부

Skill 4

전문가 검토 리포트

후보를 회계법인 임직원이 바로 검토할 수 있는 리스트로 정리합니다.

  • 우선순위와 영향 이유
  • 관련 고객군과 실무 쟁점
  • 내부 영업자료 또는 Agent 경고문으로 변환

출력

검토 리스트, 고객 안내 초안, Tax Agent 응답 가드레일

Skill 5

검증·피드백

과거 개정 사례를 정답셋으로 두고 후보 탐지 품질을 확인합니다.

  • 실제 영향 문서와 비교
  • 누락·오탐 원인 분류
  • 태그, 룰, 검색 쿼리 개선

출력

Recall, Precision, 근거율, 전문가 검토 유용성, 안전성 지표

수집할 데이터

데이터 필요도 용도 MVP 기준
부가가치세법·시행령 필수 변경 조문과 판단 요건의 기준 개정 사례 2~3개
신구조문대비표 필수 변경 전후 문구 분리 조문별 표 구조 보존
부가가치세 집행기준 필수 실무 기준 영향 탐지 쟁점별 일부 수집
국세청 해석례 필수 기존 회신 영향 후보 탐색 30~100건 샘플
내부지침/기재부/기본통칙 권장 회계법인 고유 moat 반영 샘플 3~5건
판례 제외/검증용 최신판례는 기존 Tax Agent 자산 활용 가정 정답셋 보조 자료만

파싱 방식

  • 법령은 조, 항, 호, 목 단위로 분리합니다.
  • 신구조문대비표는 변경 전과 변경 후를 별도 필드로 저장합니다.
  • 해석례는 세법해석정비 전후 비교와 보조 판단용으로만 나눕니다.
  • 집행기준은 기준번호, 제목, 관련 조문, 본문을 분리합니다.
  • 내부지침, 기재부 해석, 기본통칙은 1차 MVP에서 제외합니다.

분류 체계

납세자

영세사업자, 개인사업자, 간이과세자, 일반과세자, 면세사업자, 법인사업자

거래

세금계산서, 전자상거래, 플랫폼 거래, 부동산임대, 수출입, 용역, 면세거래

쟁점

과세대상, 면세, 영세율, 공급시기, 공급가액, 매입세액공제, 간이과세, 가산세

영향 유형

조문 직접 영향 요건 변경 대상 변경 해석 충돌 가능성 절차 변경 금액 기준 변경

검증 루프

1. 정답셋

과거 부가가치세 개정 사례 2~3개와 실제 영향 문서를 준비합니다.

2. 자동 탐색

스킬이 변경 영향 가능성이 높은 집행기준 후보를 자동으로 추출하고, 해석례로 검증·보조합니다.

3. 비교

누락, 오탐, 근거 부족, 요건 불일치를 분류합니다.

4. 개선

태그, 룰, 검색 쿼리, chunk 크기를 수정하고 다시 실행합니다.

대회에서 반드시 구현

  • 부가가치세 개정 조문 입력
  • 집행기준 샘플 인덱싱과 해석례 보조 데이터 정리
  • 영향 후보 추출
  • 영향 유형과 신뢰도 분류
  • 전문가 검토용 리스트 출력
  • 과거 사례 기반 검증 1회

안전한 응답 정책

해당 쟁점은 최근 부가가치세법 개정 조문과 연결될 수 있어 기존 해석례를 그대로 적용하기 전에 검토가 필요합니다. 시행일, 적용례, 거래시점에 따라 결론이 달라질 수 있으므로 회계법인 전문가 확인이 필요합니다.
