# LINE Seed Sans KR

인사ON Web UI는 둥근 한글 형태와 읽기 밀도를 함께 유지하기 위해 LINE Seed Sans KR의
Regular·Bold Web Font를 자체 호스팅한다.

- copyright: LY Corporation
- source: <https://seed.line.me/index_kr.html>
- release package: `LINE_SeedKR_2023.09.06`
- license: SIL Open Font License 1.1
- bundled files: `LINESeedKR-Rg.woff2`, `LINESeedKR-Bd.woff2`

공식 안내에 따라 상업적 사용을 포함한 사용이 가능하지만 글꼴 파일 자체를 별도로
판매하지 않는다. 전체 라이선스와 최신 조건은 공식 source에서 확인한다.
