# 넓은 인사규정 평가 상태

## 판정

17개 공식 source 접근과 16개 본문 파싱, 12개 자동 구조 감사, 8개 인사 topic routing 계약은 통과했다.
공식 candidate 승인자와 독립 법령 locked set은 없으므로 B0·B1·H1·H2·H3 검색,
Set Recall@5, MRR@10, 인용 정확도·완전성과 치명적 오류 수는 모두 `미측정`이다.

이 결과는 source 폭과 프로그램 경계를 검증한 것이며 법률 정답성이나 처분 정확도
향상을 뜻하지 않는다.

## 실제 확인한 분모

| 항목 | 성공/전체 | 경계 |
|---|---:|---|
| 공식 endpoint probe | 17/17 | API key 없는 exact allowlist 접근 |
| candidate 자동 구조 감사 | 12/12 | 12,640 provisions·5,777 부칙 node, 사람 승인 전 |
| 합성 개발 routing probe | 8/8 | 주제별 1건, 모두 `evidence_only` |
| PAY-01 심층 레인 회귀 | 통과 | 누락 조건 6개 재질문, 6개월·100%, 공식 교차 인용 4건, 합성 인용 0건 |
| 과거 version 부재 회귀 | 통과 | 2026-04-01 유효 version 미연결 시 인용 0건·안전 보류 |
| 독립 검토 locked legal question | 0/0 | 미구축·미측정 |

17개 registry 중 16개 법령·행정규칙 본문을 provision으로 파싱했다. 실무편람 1종은
metadata-only라 검색 본문 수와 registry source 수를 같은 값으로 표시하지 않는다.

## 실패·잔여 위험

- 독립 승인 전 candidate는 `ANSWERABLE`의 확정 근거로 승격할 수 없다.
- metadata-only 실무편람 1종은 현재 본문 검색이 되지 않는다.
- 기관 내부 규정은 수집하지 않아 `없음`이 아니라 `미확인`으로 표시한다.
- 주제별 조건 스키마가 없는 넓은 질문은 근거 후보만 주고 항상 사람 검토로 넘긴다.
- PAY-01의 2026-07-01 효력 보수규정은 별도 version으로 연결했지만, 사람 승인과 독립
  법령 정답셋이 없으므로 결과는 계속 `REVIEW_REQUIRED`다.

원시 계약은 `evals/wide-evaluation-v0.1.json`, 실제 PAY-01 통합 smoke는
`artifacts/provider/derived-allowance-smoke.json`에 있다.
