# ADR-0023 결론을 못 낼 때 조문을 넘긴다

- 상태: 채택
- 날짜: 2026-08-11
- 관련: ADR-0020(claim 수량 근거 검사), ADR-0010·0017(evidence_only lane), ADR-0022

## 배경

`local` 프로필에서 휴직 4종을 끝까지 돌려봤다.

| 유형 | 결과 |
|---|---|
| 육아휴직 | `INSUFFICIENT_EVIDENCE` · 인용 **0건** |
| 질병휴직 | `REVIEW_REQUIRED` · 모델이 실제 문장 작성 |
| 가족돌봄 | `INSUFFICIENT_EVIDENCE` · 인용 **0건** |
| 자기개발 | `REVIEW_REQUIRED` · 모델이 실제 문장 작성 |

절반이 이 한 줄로 끝났다.

> 근거 또는 검증 조건이 충분하지 않아 답변을 보류합니다.

두 실패 모두 사유는 `claim_quantity_unsupported`였다. Qwen이 인용문에 없는 기간을 썼고
ADR-0020의 수량 게이트가 잡았다. **게이트는 제 일을 했다.** 문제는 그 다음이다.

검색은 성공했다. 조문은 시점·인용 검증(`validate_temporal_and_citations`)을 통과했다.
그런데 `_safe_failure`로 빠지면서 그 조문을 전부 버리고 인용 0건으로 답했다.

사용자에게는 **검색이 실패한 것으로 보인다.** 결론을 못 내는 것과 근거를 못 찾는 것은
다른 일인데 화면이 둘을 같은 문장으로 말했다. 넓은 lane에는 같은 처리를 이미
고쳐뒀는데(ADR-0022 이전 작업) 정작 이 제품의 간판 기능인 심층 검토에는 남아 있었다.

## 결정

심층 검토에서 모델 초안이 검증에 걸리면 **초안만 폐기하고 조문은 넘긴다.**

결론은 여전히 만들지 않는다. `CLAUDE.md`의 "필수 조건이 없으면 결론을 생성하지 않는다"는
그대로다. 바뀌는 것은 화면이 말하는 내용이다.

```
전: [INSUFFICIENT_EVIDENCE] 인용 0건
    근거 또는 검증 조건이 충분하지 않아 답변을 보류합니다.

후: [REVIEW_REQUIRED] 인용 2건
    자녀 생년월일·휴직 유형·같은 자녀의 이전 육아휴직 기간·질문 기준일까지 확인했어요.
    다만 이 조건만으로 결론 문장을 만들지 않았어요.
    판단에 필요한 근거는 제63조 제2항 제4호 · 제64조 제8호이니 이 조문을 직접 확인해 주세요.
```

"판단은 담당자가"로 끝내지 않는다. 확인한 조건을 되읽어 주고 어느 조문을 봐야 하는지
조 번호로 짚는다. 문장은 전부 결정적으로 생성하며 조문에 없는 수치는 넣지 않는다 —
그것이 이 경로로 오게 된 이유이기 때문이다.

### 넘기지 않는 경우

모델 문장이 걸린 것과 근거 자체가 걸린 것은 다르다.

| 검증 실패 사유 | 처리 |
|---|---|
| `claim_quantity_unsupported` | 조문 넘김 |
| `unsupported_claim` | 조문 넘김 |
| 초안 없음(`draft_empty`) | 조문 넘김 |
| `citation_not_effective` | **보류 유지** |
| `citation_provision_not_found` | **보류 유지** |
| `citation_source_mismatch` | **보류 유지** |
| `decisive_exception_missing` | **보류 유지** |

아래 넷은 조문이 질문 기준일에 무효이거나, 저장소에 없거나, 출처가 어긋나거나, 결론을
뒤집을 부칙·단서가 빠진 경우다. 그때 조문을 넘기면 **틀린 근거를 보라고 하는 것**이 되고,
이는 지금 고치는 문제보다 나쁘다.

### 폐기 사실을 숨기지 않는다

`model_draft_discarded` 사유와 원래 검증 사유를 함께 싣고, 한계에 "생성한 초안이 인용문에
없는 값을 포함해 폐기했습니다"를 남긴다. 평가에서도 같은 사유 코드로 센다.

## 결과

`local` 실모델 휴직 4종 재측정:

| | 전 | 후 |
|---|---:|---:|
| 빈 답(인용 0건 보류) | **2/4** | **0/4** |
| 모델이 문장을 쓴 경우 | 2/4 | 2/4 |
| 조문 전달로 끝난 경우 | 0/4 | 2/4 |

잠금 회귀셋 B0~H4 지표는 움직이지 않았다. 결정적 모델은 템플릿만 쓰므로 수량 게이트에
걸리지 않고, 이 경로는 실모델에서만 열린다. **합성 평가셋이 재지 못하는 결함이었다.**

## 대안과 기각 사유

- **게이트를 완화해 모델 문장을 그대로 내보낸다** — 기각. 인용문에 없는 기간이 그대로
  화면에 나간다. ADR-0020이 존재하는 이유를 지운다.
- **초안을 다시 생성한다(retry)** — 기각. 같은 모델이 같은 corpus로 같은 실수를 반복할
  근거가 있고, 응답 시간만 늘어난다. 재시도 횟수를 어디서 끊을지도 임의값이 된다.
- **결정적 규칙으로 결론 문장을 만든다** — 기각. 그것이 곧 결론 생성이며 필수 조건이
  갖춰지지 않은 상태에서 금지된다. 조문 전달은 결론이 아니다.
