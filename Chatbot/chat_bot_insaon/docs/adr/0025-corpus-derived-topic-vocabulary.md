# ADR-0025 범위 판정 어휘를 corpus에서 뽑는다

- 상태: 채택
- 날짜: 2026-08-11
- 관련: ADR-0010·0017(넓은 lane과 심층 검토의 분리), ADR-0022(검색 후보 자격)

## 배경

화면에서 이렇게 끝났다.

```
질문:  인사의 가점을 받을 수 있는 법적인 근거들 모아봐
답변:  ● 답변할 근거가 부족해요
       인사ON은 현재 지방자치단체 일반직의 휴직·복직 질문만 지원해요.
       이 질문의 최종 판단은 지원하지 않아요.
유의:  no_supported_topic_signal
```

세 가지가 동시에 틀렸다.

1. **문장이 거짓이다.** 인사ON은 휴직·복직만 지원하지 않는다. 임용·인사기록·평정·승진·
   복무·보수·수당·징계·소청·교육훈련·퇴직 여덟 주제가 색인돼 있고 근거 검색이 된다.
   제품보다 좁게 자기를 소개하면 사용자는 되는 질문까지 시도하지 않는다.
2. **사유 코드가 영문 그대로 나갔다.** `no_supported_topic_signal`이 유의사항 항목에 있다.
3. **거절 자체의 근거가 잘못됐다.** 아래가 본론이다.

## 원인

범위 판정이 손으로 적은 단어 목록이었다.

```python
_wide_topics = {
    "appointment": ("신규임용", "임용", "채용", "전보", "경력경쟁", "시보", "결격"),
    "performance_and_promotion": ("평정", "근무성적", "승진"),
    ...
}
```

질문에 이 글자가 부분 문자열로 걸려야 검색이 시작된다. 걸리지 않으면
`no_supported_topic_signal`로 끝난다. **corpus에 조문이 있는지는 묻지 않는다.**

`가점`은 목록에 없어서 죽었다. 단어를 추가하면 그 질문은 살지만 다음은 `겸직`,
그다음은 `유연근무`다. 닫힌 어휘가 열린 어휘의 검색기 앞을 막고 있는 구조이며,
단어를 더하는 것은 고치는 것이 아니라 실패를 다음 단어로 미루는 것이다.

같은 원인으로 이미 한 번 데인 적이 있다. `직위해제`와 `공가` 조문을 corpus에 넣고도 두
질문이 근거 0건으로 끝났다. 그때는 단어를 추가해서 넘겼다. 그것이 이번 화면이다.

## 기각한 방법 — 관련도 하한

먼저 시도한 것은 "단어 목록을 걷어내고 전 주제를 검색해, 점수가 하한을 넘으면 답한다"였다.
측정까지 했다.

| 부류 | 최고 점수 |
|---|---:|
| 색인된 조문 제목으로 만든 질문 97건 | min **0.0673** · 중앙 0.184 |
| 도메인 밖 5건 | **0.0** |
| 인사 질문이지만 corpus에 없는 주제 5건 | 0.0 ~ **0.0578** |

깨끗해 보였고 0.06으로 잡았다. **실제 질문에 걸어보니 무너졌다.**

```
"2026년 8월 10일 기준 겸직 허가 기준 알려줘"  → 0.2170 (통과)
   인용: 보수·수당 부칙 / 봉급 지급일 / 특별휴가
```

점수는 관련도가 아니라 **질문과 corpus의 토큰 겹침**을 잰다. 날짜 문자열과 `기준`·`근거`·
`조문` 같은 상투어가 모든 조문과 겹치므로, 질문이 길어질수록 아무 주제나 하한을 넘는다.
분포를 잰 질의(제목 한 줄)와 실제 질의(날짜+상투어 포함)의 모양이 달랐고, 그 차이를 확인
하지 않은 채 임계값을 골랐다. 되돌렸다.

## 결정

주제 어휘를 **씨앗(손) ∪ 파생(corpus)**의 합집합으로 만든다.

```python
def topic_terms_from_titles(titles_by_topic) -> dict[str, frozenset[str]]:
    ...
```

- **파생**: 색인된 조문의 제목과 조 번호에서 한글 토큰을 뽑는다. 조문이 늘면 어휘도
  늘고, 아무도 단어를 추가하지 않아도 새 조문에 닿는다. **도달 가능성이 "누가 무엇을
  타이핑했는가"가 아니라 "저장소에 무엇이 있는가"의 성질이 된다.**
- **씨앗**: 기존 손 목록을 남긴다. `휴가`·`승진`·`시효`처럼 담당자가 쓰지만 조문 제목에
  그 글자로는 없는 말이 있다.

두 가지 필터를 건다. 둘 다 실패를 보고 넣었다.

**세 글자 이상만 뽑는다.** 조문 제목에는 `절차`·`요건`·`방법`·`시기` 같은 두 글자 일반
명사가 흔하다. 넣었더니 `계약직 재계약 절차 알려줘`가 퇴직 조문을 받았다. 기존
out-of-scope 테스트가 잡았다. 뜻이 있는 두 글자(`시효`, `정년`, `병가`)는 씨앗에 있다.

**세 개 이상의 주제에 나타나는 말은 버린다.** corpus에는 상호참조 조문과 인접 혼동
distractor가 일부러 들어 있고 그 제목이 다른 주제의 이름을 달고 있다. 거르지 않으면
`승진`이 임용·평정·징계 셋에 다 붙어 `승진 가점 근거`가 임용으로 샜다.

### 거절 문구를 나눈다

`no_supported_topic_signal`(저장소에 닿는 조문이 없다)과 `unsupported_subject_or_topic`
(이 대상·판단은 하지 않는다)은 다른 일이다. 전자에 후자의 문장을 쓰면 화면이 거짓말을
한다. 전자는 이제 이렇게 끝난다.

```
이 질문에 연결할 공개 조문을 저장소에서 찾지 못했어요.
지원 범위 밖이거나, 해당 주제의 원문을 아직 수집하지 않은 경우예요.

- 육아·질병·가족돌봄·자기개발 휴직과 복직은 필요한 조건까지 확인해 결론을 정리해요.
- 임용·인사기록·평정·승진·복무·휴가·보수·수당·징계·소청·교육훈련·퇴직은 근거 조문을 찾아 드려요.
- 국가공무원·특정직과 최종 인사처분 판단은 지원하지 않아요.
```

`no_supported_topic_signal`에 한국어 라벨을 붙였다.

## 결과

씨앗에 없던 말이 어휘에 들어왔다. 아무도 타이핑하지 않았다.

| 주제 | corpus에서 자란 말 |
|---|---|
| personnel_records | 인사기록카드 · 보존기간 · 열람과 |
| performance_and_promotion | 승진후보자명부 · 승진소요최저연수 · 승진임용의 |
| pay_and_allowance | 시간외근무수당 · 가족수당 · 정근수당 · 지급일 · 휴직기간 |
| discipline_and_appeal | 징계부가금 |
| appointment | 결격사유 · 시보기간의 |
| service_and_leave | 특별휴가 |

도달 가능성 전수 측정. 분모는 넓은 lane의 **본문 조문**이다. 구버전·미시행·단서·부칙·
인접 혼동 distractor는 닿으면 안 되는 것들이라 뺐다.

| | |
|---|---:|
| 본문 조문 | 41건 |
| 자기 제목의 말로 물었을 때 자기 조문을 인용 | **40건** |
| 실패 | **1건** (`기록 정정`) |

`기록 정정`은 제목에 3자 이상 토큰이 없다(`기록` 2자, `정정` 2자). 두 글자를 허용하면
위의 `절차` 문제가 돌아오므로 고치지 않고 `xfail`로 남겨 측정된 한계로 공개한다.

반대 방향도 고정했다. 도메인 밖 4건과 corpus에 없는 인사 주제 2건은 전부 근거 0건으로
끝난다. 어휘를 넓힌 대가로 아무 질문에나 조문을 붙이면 지금 고치는 문제보다 나쁘다.

회귀는 `tests/integration/test_wide_topic_reachability.py`가 잡는다. 조문을 넣고도 아무도
찾지 못하는 상태로 되돌아가면 여기가 깨진다.

## 대안과 기각 사유

- **관련도 하한** — 위에 적었다. 점수가 질문 길이에 흔들려 `겸직`이 보수·수당 조문을 받았다.
- **`_wide_topics`에 단어를 계속 추가한다** — 기각. 지금 고치는 문제가 그 방식의 결과다.
- **분류를 생성 모델에 맡긴다** — 기각. 기준일·적용대상 필터는 생성 모델 호출 전에
  결정적 로직으로 수행한다는 규칙에 걸린다. 범위 판정은 그 앞이다.
- **조문 본문 전체에서 어휘를 뽑는다** — 기각. 제목보다 훨씬 넓어져 두 글자 일반어 문제가
  통제 불능이 된다. 제목은 사람이 붙인 요약이라 주제어의 밀도가 높다.

## Revisit

- 파생 어휘는 제목에서만 뽑는다. 제목이 없거나 형식적인 corpus에서는 씨앗만 남는다.
  공식 candidate corpus로 바꿀 때 다시 잰다.
- 유의어는 다루지 않는다. 사용자가 `월급`이라 쓰고 corpus가 `보수`라 적었으면 여전히
  닿지 않는다. lane 안에 들어온 뒤의 유의어 확장은 ADR-0019가 다루지만, lane 밖은 아니다.
- `가점`·`겸직`·`유연근무`는 여전히 범위 밖이다. 이 corpus에 그 조문이 없기 때문이며,
  이제는 그 사실을 정확히 그렇게 말한다.
