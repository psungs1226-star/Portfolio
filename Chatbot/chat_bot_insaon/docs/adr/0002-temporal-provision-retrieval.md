# ADR-0002: 기준일 기반 조문·버전 검색

## Context

법령은 공포일과 시행일이 다를 수 있고 부칙에 별도 적용례와 경과조치가 존재한다. 현행 문서만 임베딩하면 과거 기준일 질문을 처리할 수 없다.

## Options

1. 최신 법령만 저장
2. 문서 버전은 저장하되 검색 후 LLM이 시점을 판단
3. 조문·부칙별 효력기간을 저장하고 검색 전에 기준일 필터

## Decision

3번을 선택한다. `valid_time`과 `system_time`을 분리하고, 기준일 후보 검색 후 부칙·적용례를 함께 제공한다.

## Consequences

- 수집·파싱 스키마가 복잡해진다.
- 기준일이 없는 질문에는 재질문이 필요하다.
- 과거·미시행 규정 혼용을 별도 평가할 수 있다.

## Revisit

원천 API가 항·호·목 단위 효력기간을 충분히 제공하지 않으면 문서 버전 단위 필터와 부칙 수동 태깅을 결합한다.
