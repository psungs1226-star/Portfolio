# ADR-0010: 넓은 근거 검색과 휴직·복직 심층 검토를 분리한다

## Context

기존 공개 source candidate는 지방공무원법·임용령·인사운영지침 3종이지만 실제 런타임은 합성 휴직 조문만 사용했다. 이 상태에서는 지방공무원 인사 포트폴리오로서 자료 폭이 좁고, 승진·징계·보수 같은 질문은 검색도 하지 않은 채 범위 밖 고정 문구로 종료된다.

반대로 source 수만 늘리고 모든 질문을 자동 판단하면 주제별 조건 스키마·시점 규칙·독립 평가가 없는 결론을 노출하게 된다.

## Options

1. 휴직·복직 4개 유형만 유지한다.
2. 인사 전 분야를 같은 깊이의 자동 검토로 확장한다.
3. 인사 생애주기 전체의 공식 근거 검색과 휴직·복직 심층 검토를 분리한다.

## Decision

옵션 3을 선택한다.

- `official-hr-wide.toml`에 13개 공식 자료와 8개 topic domain을 선언한다.
- source별로 `deep_review`, `evidence_only`, `metadata_only` 등급을 둔다.
- deep review는 기존 휴직·복직 조건·시점·인용 gate를 유지한다.
- evidence-only는 관련 조문 후보와 확인 항목을 제시하되 자격·금액·처분을 단정하지 않는다.
- 여러 업무 단어가 섞인 질문은 인물의 휴직 이력보다 요청한 판단 대상 topic을 우선한다. 일반 보수·수당은 evidence-only로 분류한다.
- 대화 중 deep review와 evidence-only 레인이 바뀌면 기준일만 유지하고 이전 레인 전용 조건을 제거한다.
- source·효력기간 필터 전에 `top-k`로 자르지 않으며, 기준일에 유효한 버전이 없으면 `invalid_effective_version`으로 보류한다.
- 미승인 candidate와 metadata-only 자료는 `ANSWERABLE`의 핵심 근거가 될 수 없다.
- 실제 개인정보와 기관 내부 규정은 수집하지 않는다.

## Consequences

- 포트폴리오에서 지방공무원 인사규정 전체 지형과 깊이 있는 휴직 검토를 함께 보여줄 수 있다.
- 사용자는 범위 밖 한 문장 대신 검색 가능 범위와 사람 검토 경계를 확인할 수 있다.
- source 수 증가와 법률 정답성은 별개이므로 wide snapshot 수집·사람 승인·독립 주제별 평가가 추가로 필요하다.
- 화면은 `근거 검색`과 `심층 검토`를 혼동하지 않게 review tier를 표시해야 한다.
- 이후 ADR-0013에서 `육아휴직 복직자 + 정근수당 지급률`만 별도 조건·계산·평가 계약이
  준비된 제한적 deep-review 예외로 승격했다. 정근수당 외 보수·수당 경계는 바뀌지 않는다.

## Revisit

- evidence-only 주제별 조건 스키마와 독립 잠금셋이 준비될 때
- 기관 규정 수집 범위를 검토할 때
- 공식 source 구조나 이용조건이 바뀔 때
