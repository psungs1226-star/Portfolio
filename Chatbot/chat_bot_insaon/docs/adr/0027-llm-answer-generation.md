# ADR-0027 LLM 기반 답변 생성으로 전환한다

- 상태: 채택
- 날짜: 2026-08-12
- 관련: ADR-0010(offline/local 프로필 분리), ADR-0023(evidence handover)

## 배경

현재 offline 프로필의 `DeterministicReviewModel`은 검색 결과와 무관하게 고정 템플릿
문장("질문 기준일에 유효한 예시 공개 근거를 확인했어요")을 반환한다. 조건 게이트와
검색이 정상 동작해도 사용자에게는 모든 답이 같은 한 줄로 보여, "작동하지 않는다"는
인상을 준다.

local 프로필의 `OllamaReviewModel`은 실제 LLM이 조문을 읽고 문장을 만들지만,
Ollama + 3.7GB 모델 다운로드가 필요해 공개 데모 진입 장벽이 높다.

## 결정

**Ollama 로컬 모델(qwen3:4b-instruct)을 사용한 답변 생성을 기본으로 한다.**

### 파이프라인 변경

```
변경 전 (offline):
  분류 → 조건 게이트 → RAG 검색 → 템플릿 문장 (LLM 없음)

변경 후 (local):
  분류 → 조건 게이트 → RAG 검색 → LLM이 조문을 읽고 답변 작성 → 사후 검증
```

### 단계별 계획

1. **답변 생성 프롬프트 개선** (이번 작업)
   - `OllamaReviewModel`의 시스템 프롬프트를 개선해 조문 내용을 자연스러운 한국어로 정리
   - 검색된 조문의 핵심 내용(기간, 요건, 절차)을 구조화해서 전달
   - 기존 사후 검증(인용 검증, grounding) 유지

2. **검색 쿼리 플래닝** (함께 구현)
   - `OllamaQueryPlanner` — LLM이 질문을 분석해 법령 용어 검색 쿼리를 생성
   - `QueryTransformer` 프로토콜을 구현해 기존 파이프라인에 투명하게 연결
   - local 프로필의 `RetrievalPipeline`에 연결, H4 config에서 활성화
   - 실패 시 빈 결과 반환(graceful degradation) — 기존 검색은 그대로 동작

### 유지하는 것

- 개인정보 검사(PrivacyGate) — LLM 호출 전 차단
- 기준일·적용대상 시점 필터 — LLM 호출 전 결정적 로직
- 인용 검증(CitationValidator) — LLM 출력 사후 검증
- 수량 grounding — LLM이 주장한 숫자가 조문에 있는지 확인
- 세 가지 결말(ANSWERABLE/REVIEW_REQUIRED/INSUFFICIENT_EVIDENCE)

### 바꾸는 것

- offline 프로필의 `DeterministicReviewModel` → 템플릿 유지하되 공개 데모 기본 진입점
- local 프로필 → LLM 답변 생성이 실제로 동작하는 프로필로, 포트폴리오 시연의 주 경로
- 대시보드 기본 프로필 → local로 전환 (Ollama 설치 안내 포함)

## 근거

- 포트폴리오 리뷰어가 30분 안에 "이 시스템이 실제로 법령을 읽고 답한다"는 것을
  확인할 수 있어야 한다. 템플릿 한 줄로는 불가능하다.
- LLM 생성 문장은 사후 검증으로 이중 잠금돼 있어 안전 규칙을 깨지 않는다.
- Ollama는 API key 없이 로컬에서 무료로 돌아가므로 시연 비용이 0이다.

## 위험

- Ollama 미설치 환경에서 local 프로필이 실패한다 → offline 폴백을 유지해 에러 대신
  템플릿 답변이라도 나오게 한다.
- LLM이 조문에 없는 내용을 생성할 수 있다 → 기존 grounding 검증이 이를 잡아
  문장을 폐기하고 조문만 전달한다(ADR-0023 evidence handover).
- 응답 시간이 늘어난다 → 포트폴리오에서는 측정해서 한계로 공개하면 되므로 OK.

## 실측 결과

### 답변 퀄리티 (Ollama qwen3:4b-instruct + offline 합성 corpus)

| 질문 | 변경 전 (템플릿) | 변경 후 (LLM) |
|---|---|---|
| 휴직 중 봉급? | "유효한 예시 공개 근거를 확인했어요" | "질병휴직은 최초 1년까지 봉급의 7할, 1년을 넘는 기간은 5할을 지급하고, 그 밖의 휴직은 봉급을 지급하지 않는다" |
| 징계 종류? | "유효한 예시 공개 근거를 확인했어요" | "징계는 파면, 해임, 강등, 정직, 감봉, 견책으로 구분된다" |

### 응답 시간

- H3 (쿼리 플래닝 없음): 20~35초 (LLM 생성 포함)
- H4 (쿼리 플래닝 포함): 20~40초
- offline (템플릿): < 1초
