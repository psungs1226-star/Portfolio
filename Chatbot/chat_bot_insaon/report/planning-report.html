SCQA problem definition

핵심 문제 | 적용 근거의 선택

같은 ‘휴직’ 질문도 유형, 사람, 기간, 기준일과 예외조건에 따라 확인해야 할 근거가 달라진다.

S
Situation
인사과는 육아·질병·가족돌봄·자기개발 휴직과 복직 문의를 반복적으로 검토한다.
C
Complication
근거가 여러 규정에 분산되고, 본문·단서·부칙과 시행일이 서로 다른 판단조건을 만든다.
Q
Question
최종 결정을 자동화하지 않으면서도, 누락 조건과 기준일을 반영한 근거 검토를 어떻게 지원할 것인가?
A
Answer
유형 분류·재질문·시점형 RAG·인용 검증·답변 보류를 하나의 대화 흐름으로 묶는다.
